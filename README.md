# FreeToolHub - SEO + Responsive + Google AdSense

GitHub Pages-ready static website for `https://sehdevverma.github.io/free-tool-hub/`.

## Included
- Responsive mobile/tablet/desktop layout
- GST, EMI, percentage, age and unit calculators
- Image compressor
- UPI QR generator
- Invoice generator
- SEO titles, descriptions, canonicals, robots.txt and sitemap.xml
- Google AdSense publisher ID configured as `ca-pub-5821164202370457`
- `ads.txt` configured as `google.com, pub-5821164202370457, DIRECT, f08c47fec0942fa0`
- GitHub Pages 404 page

## Upload
Extract this ZIP and upload the complete contents to the root of the `free-tool-hub` repository. Keep the `tools/` and `assets/` folders.

## AdSense
The AdSense code is present, but ads normally require Google to approve/verify the site before ads serve. In AdSense, add the exact GitHub Pages site URL and complete the verification/review process.
